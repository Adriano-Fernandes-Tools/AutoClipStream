# GTA | Acervo da adaptação anterior

O acervo adaptou ideias de canais de Fortnite e de um canal sobre criação de conteúdo para imaginar cortes de lives de GTA 6. As missões, fugas, comparações entre jogos e falas ilustrativas servem como pautas. Para publicar um exemplo, localize a cena e confirme o que o streamer efetivamente disse ou fez.
